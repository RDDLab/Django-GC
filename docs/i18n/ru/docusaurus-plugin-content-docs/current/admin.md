Django-GC использует штатный список и форму Django Admin. Видимость записей учитывает права провайдеров.

`GlobalConfigAdmin` и `GlobalConfigCategoryAdmin` регистрируются на
`admin.site` как обычные `ModelAdmin`. История Admin — Django `LogEntry`.

- права add и delete всегда ложны
- ключи, типы, описания и числовые категории только для чтения
- подписи категорий и варианты фильтра берутся из `GLOBAL_CONFIG_CATEGORIES`
- страница категории показывает сохранённый ID и вычисленные code/name только для чтения
- `list_filter` покрывает разрешённую категорию, тип и read-only
- поиск покрывает ключ, описание, код и название категории из definitions

Форма выбирает виджет по `SettingType`: HTML5 date/time, password для `SECURE`, массивы через точку с запятой и checkbox для множественного выбора.

Числовые поля сравнивают введённое число с сохранённым значением.

Read-only ключи блокируют поле значения. Обязательные ключи нельзя сохранить пустыми.

<Changed v="1.1.5" />

Каталог показывает описание, значение, тип, ключ и категорию. SECURE маскируется. Изменяется только значение; readonly защищён также на сервере. Интегрирующий проект может открывать редактор в модальном окне Chassis, сохраняя проверки и подтверждение библиотеки-владельца.

Колесо включает шаблон `admin/django_gc/configuration_metadata.html`, который доступен штатному загрузчику Django. Проект может расширить форму, чтобы открывать её в своём модальном окне.

## Языки

Django-GC поставляет английские и русские переводы подписей админки, типов
настроек, сообщений валидации и команды инициализации. Библиотека использует
активный язык Django. Если перевод отсутствует, выводится исходный английский
текст. Для переключения между английским и русским добавьте оба языка в
`LANGUAGES` проекта и настройте `LocaleMiddleware` Django.

Проекты и провайдеры переводят собственные описания настроек, названия категорий
и подписи вариантов выбора в каталогах своих приложений. Для проверки переводов
из локальной копии репозитория выполните
`bash .github/scripts/compile-translations.sh`. В опубликованные колеса входят
скомпилированные каталоги Django-GC.
