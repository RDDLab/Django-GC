<Since v="1.0.1" />

История в Admin — встроенный журнал Django `LogEntry`. Пакет не зависит от
`django-simple-history`.

Когда оператор меняет значение или название категории в Admin, Django
записывает автора и время. Записи открываются кнопкой **History** на
странице объекта.

`set_value()` — программная запись. Она не создаёт `LogEntry` Admin.
Если проекту нужен audit trail сервисных записей, его ведёт доменный журнал
проекта.

Значения `SECURE` шифруются до `save()`, если задан
`GLOBAL_CONFIG_ENCRYPTION_KEY`, поэтому в Admin history не попадает только
что введённый секрет открытым текстом.
